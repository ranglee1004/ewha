# 모카와 동승 — 차량용 펫 동승 케어 시제품

첨부된 와이어프레임의 여행 케어, 병원 연계, 건강 기록·설정 흐름을 구현한 브라우저 시제품입니다.

## 실행
`web/index.html`을 정적 웹 서버로 제공합니다. 외부 라이브러리나 서버 API 없이 동작합니다. 휴대폰 가로·세로 화면을 지원합니다.

## 구현 범위
- 홈, 출발 전 4항목 체크, 주행 관찰, 예시 음성 기록, 휴식 제안, 정차 후 돌봄, 이동 리포트
- 병원 안내, 수의사용 상담 요약 및 복사, 응급 병원 경로 시연
- 건강 기록 필터, 일정/기록 추가, 반려견 프로필 및 음성 안내 설정
- 기록과 프로필은 브라우저 localStorage에 저장. 기기 간 동기화하지 않음.

## 시연 범위
차량 공조·주행·경로·병원 정보와 행동 변화는 모두 모의 데이터입니다. 실제 Pleos SDK, 내비게이션, 카메라, 진료 예약, 전화 연결, 마이크 음성 인식은 연결되지 않았습니다. 음성 안내는 브라우저 speechSynthesis 지원 시 재생합니다. 사진과 병원 정보는 예시이며 건강 진단 기능은 없습니다.

## 검증
JavaScript 문법 검사, 브라우저에서 체크리스트 활성화, 관찰 기록 입력, 돌봄 저장, 리포트 및 상담 요약 연결 확인. 390×844, 844×390 크기의 브라우저 프레임에서 레이아웃 확인. 실제 iOS Safari 및 Pleos 에뮬레이터 실행은 미검증.

동일 화면을 담은 Android release APK는 저장소 루트 `apk/` 폴더에 있습니다. 빌드·서명 검증은 통과했으며 Pleos 실행은 미검증입니다.

## 와이어프레임 반영 수정
- 홈 4개 진입: 여행 케어 / 병원 / 회복 케어 / 응급 병원. 건강 기록은 좌측 기록 메뉴에 유지.
- 병원 가는 길 → 상태 기록 → 병원 도착·주차 → 수의사용 요약 → 회복 귀가 시작.
- 회복 귀가는 목적지를 집으로 바꾸고 별도 이동 기록을 시작. 휴식 후에도 회복 귀가 상태를 유지.
- 이동 리포트에 이동 요약 / 관찰 기록 / 돌봄 기록 탭 제공.
- 응급 화면의 다른 병원 선택과 일정 폼의 취소 버튼 동작 보완.
- 이번 변경 검증: JavaScript 문법 검사, 독립 상태 전이 테스트 통과. 브라우저 미리보기는 접속 정책 제한으로 이번 수정본 시각 검증 불가.

## 저장소 구성
- `web/`: 최신 브라우저 시제품 소스.
- `android/`: 같은 화면을 로컬 WebView로 표시하는 Kotlin Android 프로젝트. Android Studio에서 이 폴더를 열어 실행.
- Android 준비 환경: JDK 17, Android SDK 35, Gradle Wrapper 8.9.
- Android release 빌드·서명 검증 통과. Pleos 에뮬레이터 설치·실행은 미검증. 검증 기록은 `../apk/VALIDATION.md` 참고.
- 현재 Kotlin 코드는 WebView 실행용이며, 차량 SDK를 사용하는 네이티브 화면 구현은 아직 없음.
